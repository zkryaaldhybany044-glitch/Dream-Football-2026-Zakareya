# Dream Football 2026 — Zakareya

لعبة كرة قدم ثلاثية الأبعاد للمتصفح والهواتف. هذه نسخة تجريبية متقدمة قابلة للتطوير، وليست لعبة تجارية بمستوى DLS26 حتى الآن.

## التشغيل
- افتح الموقع المنشور عبر GitHub Pages أو افتح `index.html` من خادم محلي.
- اضغط **ابدأ المباراة**.
- الهاتف: عصا الحركة + تمرير + تسديد + بينية + افتكاك + تبديل لاعب + تبديل كاميرا.
- الكمبيوتر: WASD أو الأسهم للحركة، Space للتسديد، X للتمرير، C لتبديل الكاميرا.

## محتويات الإصدار
- ملعب ثلاثي الأبعاد مع خطوط منطقة الجزاء والمرمى والشباك.
- 22 لاعباً بأجسام بشرية إجرائية مفصلة (رأس، وجه مبسط، جسم، ذراعان، ساقان ومفاصل).
- تحريك جري وحركة قدمين وذراعين، حمل الكرة، تمرير وتسديد وفيزياء ارتداد مبسطة.
- ذكاء اصطناعي تموضعي للفريقين: ضغط، تغطية، دعم هجومي وتحرك حسب المركز.
- حارسان يتحركان أفقياً ويتفاعلان مع التسديدات.
- مدرجات ومقاعد وجمهور متعدد الألوان باستخدام InstancedMesh لتقليل كلفة الرسم.
- احتفالية هدف تلقائية بحركة قفز ودوران وهبوط وفتح الذراعين مع ظهور SIUUUU.
- واجهة لمس متجاوبة وثلاث زوايا كاميرا.
- ملفات PWA للتثبيت على شاشة الهاتف، وخط سير GitHub Actions لنشر Pages.

## النشر على GitHub Pages
1. افتح **Settings → Pages** في المستودع.
2. في **Build and deployment** اختر **GitHub Actions** كمصدر النشر.
3. افتح **Actions** وتأكد من اكتمال سير العمل **Deploy Dream Football 2026**.
4. سيكون الموقع على:
   `https://zkryaaldhybany044-glitch.github.io/Dream-Football-2026-Zakareya/`

## التثبيت على Android
بعد نشر Pages وفتح اللعبة في Chrome، افتح قائمة المتصفح واختر **Install app** أو **Add to Home screen**. يحتاج تحميل Three.js إلى اتصال بالإنترنت عند تشغيل اللعبة؛ ملفات PWA تخزن غلاف التطبيق الأساسي فقط.

## تنزيل المشروع

## ملاحظات واقعية وحقوق
- اللاعبون ممثلون بنماذج بشرية إجرائية ثلاثية الأبعاد، وليست وجوهاً فوتوغرافية أو مسحاً مطابقاً للاعبين الحقيقيين.
- أسماء اللاعبين والتشكيلات أمثلة داخل النموذج وقد لا تعكس آخر قوائم الأندية.
- الشعارات والأطقم والوجوه الرسمية تتطلب أصولاً مرخصة. لا تتضمن هذه النسخة أصول DLS أو صوراً رسمية.
- الذكاء الاصطناعي والفيزياء والأنيميشن أنظمة أولية؛ لا تدّعي هذه النسخة محاكاة احترافية كاملة أو جودة DLS26.
- المشروع تطبيق ويب/PWA وليس ملف APK أصلياً. يمكن تثبيته من المتصفح على Android بعد نشره.
