# Dream Football 2026 — Zakareya

نموذج أولي للعبة كرة قدم ثلاثية الأبعاد يعمل في متصفح الهاتف والكمبيوتر.

## التشغيل
- افتح `index.html` عبر متصفح حديث مع اتصال بالإنترنت.
- اضغط «ابدأ المباراة».
- الهاتف: استخدم عصا اللمس وأزرار التمرير والتسديد والتبديل والكاميرا.
- الكمبيوتر: استخدم WASD أو الأسهم للحركة.

## التقنيات
- Three.js عبر jsDelivr ES modules.
- JavaScript وHTML وCSS.
- جاهز للنشر كصفحة GitHub Pages.

## نشر اللعبة عبر GitHub Pages
1. افتح إعدادات المستودع **Settings → Pages**.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

## حالة المشروع
هذه نسخة تأسيسية قابلة للتجربة، وليست لعبة مكتملة أو بمستوى DLS26 بعد. نماذج اللاعبين والذكاء الاصطناعي والفيزياء والأنيميشن عناصر أولية تحتاج إلى تطوير متدرج. استخدام شعارات الأندية والأطقم والصور الرسمية يتطلب التحقق من حقوق استخدامها.
