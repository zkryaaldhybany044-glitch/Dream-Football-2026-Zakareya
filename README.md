# Dream Football 2026 — Zakareya

لعبة كرة قدم ثلاثية الأبعاد تعمل في متصفح الهاتف والكمبيوتر باستخدام Three.js.

## تشغيل اللعبة
افتح رابط GitHub Pages بعد تفعيله في إعدادات المستودع، أو افتح `index.html` عبر خادم محلي يدعم JavaScript modules. تحتاج اللعبة إلى اتصال بالإنترنت لتحميل Three.js من jsDelivr.

## التحكم
- الهاتف: عصا التحكم الافتراضية للحركة.
- السرعة: اضغط مطولاً على زر «سرعة».
- التسديد: زر «تسديد».
- التمرير: زر «تمرير».
- البينية: زر «بينية».
- تبديل اللاعب: زر «تبديل».
- الكاميرا: زر «الكاميرا».
- الكمبيوتر: WASD أو الأسهم للحركة، وShift للسرعة.

## محتويات الإصدار الحالي
- ملعب ثلاثي الأبعاد مع خطوط ومناطق جزاء ومرميين وشباك.
- مدرجات، سقف ملعب، كشافات وجمهور منخفض التفاصيل باستخدام InstancedMesh.
- 22 لاعباً مع أجسام وأطقم وأرقام وأسماء مستوحاة من قوائم موسم 2026/27 المنشورة رسمياً.
- حركة أطراف أساسية للجري، مع سرعة ومراوغة بالكرة.
- ذكاء اصطناعي تمهيدي للتمركز والضغط والتحرك للأمام والتمرير والتسديد.
- حارسان يتحركان أفقياً ويحاولان التصدي.
- فيزياء أولية للكرة مع الجاذبية والارتداد والاحتكاك.
- كاميرات متعددة واحتفالية هدف تلقائية مستوحاة من SIUUUU.

## النشر عبر GitHub Pages
1. افتح المستودع ثم **Settings → Pages**.
2. تحت **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. انتظر ظهور رابط الموقع داخل صفحة Pages.
